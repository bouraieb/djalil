مخزني الذكي: نسخة محلية مع نسخ احتياطي

ارفع index.html وsw.js وmanifest.webmanifest وicon.svg إلى المجلد نفسه في موقع HTTPS، مثل مصدر GitHub Pages الحالي. احتفظ بنسخة من ملفات المشروع القديمة قبل الاستبدال.
افتح الموقع عبر الإنترنت أول مرة وانتظر رسالة تجهيز العمل دون إنترنت. بعد ذلك اختبر إغلاقه وفتحه دون اتصال، ثم جرّب إضافة منتج وتصدير نسخة واستيرادها باستخدام بيانات تجريبية.
زر التثبيت يظهر فقط عندما يتيحه المتصفح. يمكن استخدام إضافة إلى الشاشة الرئيسية من قائمة المتصفح حيث تتوفر. تختلف متطلبات التثبيت بين الأنظمة، والأيقونة الحالية SVG؛ بعض المتصفحات قد تحتاج أيقونات PNG بحجمي 192 و512 قبل عرض خيار التثبيت.

النقل بالبلوتوث: اضغط تصدير نسخة احتياطية، ابحث عن ملف JSON في تنزيلات جهازك، وأرسله باستخدام مشاركة الملفات في النظام إذا كان الجهازان يدعمان نقل الملفات بالبلوتوث. افتح التطبيق في الجهاز المستقبل واضغط استيراد نسخة احتياطية واختر الملف. التطبيق لا يتحكم بالبلوتوث مباشرة.
الاستيراد يستبدل البيانات ولا يدمجها. صدّر بيانات الجهاز المستقبل قبل الاستيراد. تجنب إدخال حركات مستقلة على جهازين ثم توقع دمجها.

البيانات تبقى في المتصفح وعلى عنوان الموقع المستخدم فقط. تغيير العنوان أو المتصفح أو مسح بياناته قد يفصل البيانات أو يحذفها. هذه ليست قاعدة بيانات سحابية ولا نظام مستخدمين. لا تستخدمها لمخزون حقيقي قبل اختبار الحفظ والاستعادة.

هذه النسخة تضيف النسخ الاحتياطي وفحص البيانات وملفات العمل دون اتصال. لا تتضمن تحرير المنتجات أو حذفها، الأسعار والموردين، تصحيح الحركات أو الدمج التلقائي. لم تُختبر داخل متصفح أو على أجهزتك في هذه المحادثة.
