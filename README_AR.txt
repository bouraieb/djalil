مخزني الذكي — مصدر مصحح مع مشروع Android تجريبي

لم يُبنَ هذا المشروع أو يُختبر على جهاز. لا يُعد نسخة إنتاج أو ملف APK جاهزًا.

احتفظ بنسخة احتياطية من بياناتك وملفات المستودع قبل الاستبدال.
ارفع محتويات هذه الحزمة إلى جذر مستودع djalil على master، وليس المجلد الحاوي نفسه.
يجب أن يكون codemagic.yaml بجانب index.html، ومجلد android بجانبهما.
في Codemagic اختر Check for configuration files ثم Build Makhzani Android APK.
الناتج المتوقع APK تجريبي موقّع بمفتاح debug، وليس إصدار Google Play.
احتفظ بمفتاح التوقيع الثابت قبل توزيع التطبيق؛ تغيّر مفتاح debug بين بيئات البناء قد يمنع التحديث فوق النسخة السابقة. لا تحذف التطبيق لحل ذلك قبل تصدير بياناته.

Android يفتح ملفات ويب محلية داخل WebViewAssetLoader، بلا حاجة لتنزيلها أول مرة ولا إذن اتصال بالإنترنت. النسخ الاحتياطي يستخدم منتقي حفظ ملفات Android، والاستعادة تستخدم منتقي فتح الملفات. يلزم اختبارهما فعليًا.
بيانات APK منفصلة عن بيانات المتصفح؛ نقلها يدويًا عبر تصدير واستعادة JSON.

الكمبيوتر: النسخة هي تطبيق ويب وليست EXE. انشر ملفات الويب السبعة في نفس مجلد HTTPS وافتحها أول مرة بالإنترنت. استخدم تثبيت التطبيق إن عرضه المتصفح، ثم اختبر إعادة فتحه دون إنترنت.
لا توجد مزامنة تلقائية. مسح بيانات المتصفح أو التطبيق قد يحذف المخزون.
لا تستخدم مخزونًا حقيقيًا قبل اختبار الإضافة والدخول والخروج والتصدير والاستعادة وإغلاق التطبيق وفتحه دون إنترنت.
لا يزال التطبيق لا يتضمن تعديل المنتجات وحذفها أو الأسعار أو الموردين أو الدمج بين أجهزة.

فحص المصدر: إزالة نص الدردشة بعد HTML، المسارات النسبية متوافقة، PNG 192/512، تحديث ملفات الويب عبر الشبكة مع الرجوع للنسخة المحلية دون اتصال، عدم تغيير مفتاح البيانات makhzani-smart-v1.
